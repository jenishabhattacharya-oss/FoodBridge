SharePlate — Project Overview

A web platform that moves surplus food to the people who need it. November 2026.

1What the website is

SharePlate connects donors with surplus food to verified NGOs, with volunteers delivering between them. A donor posts food with photos and a pickup window; an NGO reviews it for safety and accepts it; a volunteer collects and delivers it; the NGO confirms receipt. Every step is tracked end-to-end — status, timestamps, photos and recipient details.

DonorPosts surplus food with three safety photos (overview, close-up, label), food details, allergen notes, a pickup window and a mapped address.
NGOReviews the incoming safety queue, accepts or rejects listings, can run the pickup itself when no volunteer is available, and confirms receipt.
VolunteerClaims accepted pickups, shares live location during delivery, uploads proof of delivery, and earns a fixed ₹500 fee per confirmed delivery.

2How it works — the donation lifecycle

3Rules that make it trustworthy

  • Three separate roles — Donor, NGO, Volunteer. Each account is exactly one role, with its own workspace and server-enforced role-based access control.
  • NGOs are verified — a newly registered NGO can log in but cannot act on any listing until staff approve it in the admin panel.
  • Volunteers see only accepted pickups — and can hold one active pickup at a time.
  • Object-level permission checks — every page verifies the caller actually owns or is assigned to the record, not just that they are logged in.
  • Full audit trail — status changes, timestamps, photos and recipient details are stored on every donation and pickup.

5How the AI food-safety screening works

When a donor submits photos, the system screens them with the Google Gemini vision API before a human ever sees them:

  1. The photos are sent to the model with a strict prompt: check only visible warning signs (spoilage, mold, pests, damaged packaging). The model must reply in JSON with a decision — approve, reject, or review — plus a confidence score and risk flags.
  2. The reply is parsed, validated and range-checked before any status changes.
  3. Graceful degradation: if there is no API key, the model is unsure, or the API fails, the listing goes to a human-in-the-loop review queue instead of being blocked. Reviewers are reminded that a visual check is not a food-safety certification.

8Complete feature list

Everything the platform can do today, grouped by category:

Core workflow

  • End-to-end donation tracking — status, timestamps, photos at every step
  • Pickup windows with mapped address and coordinates
  • NGO accept / reject with a reason shown to the donor
  • NGO-managed pickup — the no-volunteer fallback path

Safety & trust

  • AI food-photo screening — auto approve / reject / flag
  • Human-in-the-loop review queue when AI is unavailable or unsure
  • Verified NGO onboarding — staff approval before any action
  • Photo evidence at every handoff — 3 safety photos, delivery proof, receipts

People & access

  • Role-based workspaces — separate dashboards for donor, NGO, volunteer
  • Role-specific registration — collects the right profile data up front
  • Object-level permission checks on every page
  • Admin panel oversight for staff approvals and interventions

Location & logistics

  • Interactive maps on listings (OpenStreetMap + Leaflet)
  • Address geocoding — type an address, get coordinates
  • Live location sharing by volunteers during delivery
  • One-active-pickup rule so volunteers are never overcommitted

Payments

  • Fixed ₹500 delivery fee collected from NGOs (Razorpay Checkout)
  • Payout release to volunteers (RazorpayX)
  • UPI / bank payout profiles — masked when displayed
  • Event-driven webhooks drive the full payment lifecycle
  • Encryption at rest for payout details and tokens

Convenience

  • Voice-assisted form filling — donors can speak their donation
  • Installable PWA — add to home screen, works on low-end phones
  • Dashboard quick stats for every role
  • Delivery history with proof photos for volunteers

Platform & operations

  • One-command demo seeding — a populated demo in seconds
  • Health endpoint + scheduled keep-alive so the site stays up
  • Dockerised deployment with auto-deploy on git push
  • Optional integrations — everything degrades gracefully
  • Password-reset e-mail (SMTP, optional)

9Current state

  • 73 automated tests across 9 modules, all passing; config and migration checks clean.
  • Deployed and live at https://shareplate-mvp.onrender.com with demo accounts and demo data seeded automatically on first boot; a scheduled GitHub Actions job keeps the free hosting tier awake.
